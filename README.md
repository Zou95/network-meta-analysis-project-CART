# Network meta-analysis of CAR-T therapies in second-line R/R large B-cell lymphoma
A frequentist network meta-analysis comparing second-line CAR-T therapies (axicabtagene ciloleucel, tisagenlecleucel, and lisocabtagene maraleucel) in adults with primary refractory or early relapsed (≤12 months after completion of first-line therapy) large B-cell lymphoma eligible for second-line treatment
